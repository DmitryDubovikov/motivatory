# Два вида распределений

Четыре одностраничных документа для читателя 10–11 лет: скроллителлинг с работающими моделями на canvas. Числа рождаются прямо в браузере из `Math.random()`, а не нарисованы заранее, — поэтому кнопка «ещё раз» имеет смысл: каждый прогон другой, а вывод один и тот же.

Каждый файл самодостаточен: один HTML, без внешних зависимостей, открывается двойным щелчком и работает офлайн. Читать по порядку — каждый следующий стоит на предыдущем.

| № | Документ | Про что | Чем кончается |
|---|---|---|---|
| 1 | [`kolokol-i-khvost.html`](kolokol-i-khvost.html) — Два вида распределений | доска с гвоздиками, рост людей, города Аргентины; откуда берутся две разные формы | мерить себя средним имеет смысл только там, где результат упирается в тебя одного |
| 2 | [`potolka-net.html`](potolka-net.html) — Потолка нет | три тысячи живых людей и одна черта: что лежит справа от того, кто делает как все | «как все» — не середина, а левый край; слева проценты, справа разы |
| 3 | [`usilitel.html`](usilitel.html) — Мир умножает фору | двадцать одинаковых игроков, растущая сеть, четыреста параллельных жизней | старание — не билет, а множитель шансов, и двигает оно всю кривую сразу |
| 4 | [`chislo-popytok.html`](chislo-popytok.html) — Почему решает число попыток | шестьдесят попыток одного человека, лучший результат из тысячи | неудачная попытка стоит только вложенного, удачная не ограничена ничем |

Оглавление для браузера — [`index.html`](index.html).

## Как это устроено

Все четыре документа собраны по одной схеме: тёмная тема с общей палитрой в `:root`, единица документа — секция (заголовок, текст, симуляция, абзац «что мы сейчас увидели»), общий движок сцен `defineScene(id, {init, draw, isDone, holdSec})` с одной `requestAnimationFrame`-петлёй, рисующей только активную сцену. Сцена запускается сама, когда доходит до середины экрана, держит финальный кадр и перезапускается.

Правила жанра, драматургия, требования к честности моделей и техкаркас — в [`promty-motivatory.md`](promty-motivatory.md). Там же готовые задания на три следующих документа серии: «Шум», «Кривое окно», «Что впереди».
