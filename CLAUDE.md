# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Не программный проект, а серия **самодостаточных HTML-документов** (скроллителлинг с симуляциями на canvas) для читателя 10–11 лет, на русском языке. Каждый документ — один файл: `<style>` в голове, `<script>` в конце, ноль внешних загрузок (ни шрифтов, ни библиотек, ни картинок). Открывается двойным щелчком, работает офлайн. Публикуется как GitHub Pages (`.nojekyll`, `index.html` — оглавление).

Нет сборки, нет пакетного менеджера, нет тестов и линтера. «Запустить» = открыть файл в браузере (`open 01-delay-kak-vse.html`). Единственная проверка, которая тут есть, — прогон вероятностной модели вне страницы (node/python) для сверки чисел из текста; см. ниже.

## Обязательное чтение перед правкой

- `promty-motivatory.md` — канон: жанр, драматургия, требования к честности моделей, техкаркас, правила именования файлов, и готовые задания на документы 04–06. Промпт на новый документ = раздел «Общая рамка» + раздел «Документ N», целиком.
- `README.md` — главный тезис серии и порядок занятий (номер в имени файла = порядок чтения с ребёнком).
- `01-delay-kak-vse.html` — эталон по тону, вёрстке и устройству кода. Новый документ пишется по нему.

## Архитектура документа

Все документы собраны по одной схеме — движок и утилиты **скопированы в каждый файл** (общего модуля нет и быть не может: файл обязан быть самодостаточным). Правя движок в одном документе, реши осознанно, нужно ли то же в остальных.

**Единица документа — секция.** Заголовок → 2–3 абзаца текста → симуляция → абзац «что мы сейчас увидели» (`p.after`). Разметка:

```html
<section id="s3" data-title="Короткое имя">   <!-- data-title → точки-навигация справа -->
  <div class="wrap">
    <p class="kicker">Акт II · Подпись акта</p>
    <h2>…</h2><p>…текст до…</p>
    <div class="stage"><canvas id="cv-s3"></canvas></div>   <!-- id канваса = 'cv-' + id секции -->
    <div class="actbar"><button class="again" data-again="s3">ещё раз</button><span class="tag">…</span></div>
    <p class="after">…текст после…</p>
  </div>
</section>
```

**Движок сцен** (`01-delay-kak-vse.html:316–361` и параллельные места в 02/03):

- `defineScene(id, {init, draw, isDone, holdSec, again})` регистрирует сцену в `SCENES` по id секции.
- Один `requestAnimationFrame`-цикл `loop()` рисует **только активную сцену**. Активная = та, чей центр ближе к центру экрана (`pickActive()` на скролле; не IntersectionObserver-порог — секция с длинным текстом бывает выше экрана).
- `draw(ctx, W, H, st, dt)` — состояние сцены живёт в `st`, время в `st.t`. Когда `isDone(st)` истинно, финальный кадр держится `holdSec` секунд (по умолчанию 8) и сцена перезапускается через `initScene`.
- `fit()` масштабирует canvas под devicePixelRatio; resize переинициализирует активную сцену.
- `prefers-reduced-motion` не отключает анимацию, а ускоряет её: `SPEED = REDUCED ? 6 : 1`, множитель к `dt`.

**Утилиты — переиспользовать, а не писать заново:** `T()` (текст на канве), `line()`, `rrect()`, `gauss()`, `pareto()`, `fmt()` (пробелы в тысячах), `plural()` (согласование числительных — «5 партий», не «5 партия»), `lerp`, `clamp`, `easeOut`, `easeInOut`, `person()`.

**Палитра.** Токены в `:root` (`--bg:#0d1117`, `--ink:#e8eef6`, `--blue:#5ba8f5`, `--gold:#f0a83c`, `--green:#5fd38d`, `--red:#f2686c`, `--violet:#b98cf0` и др.) продублированы в объекте `C` в JS — canvas рисует теми же значениями. **Палитру не менять:** документы должны выглядеть как одна серия.

**Готовые блоки вёрстки:** `.two`+`.col` (две колонки, схлопываются на 640px), `ul.take` (итоговый список «Что стоит унести»), `p.fine` (постскриптум «проверь сам»), `hr.rule`, `.scrollhint`, полоса прогресса чтения сверху. Шрифты через `clamp()`; мобильный вид обязателен.

## Правила содержания (нарушать нельзя)

- **Симуляция настоящая.** Числа рождаются из `Math.random()` в браузере, а не нарисованы заранее — поэтому «ещё раз» и имеет смысл. Никогда не подгонять результат под текст.
- **Числа в тексте проверены.** Утверждение вида «в семи случаях из десяти» — прогнать модель вне страницы (node/python, большое число повторов) и убедиться, что доля сходится. Это и есть здешний аналог тестов.
- **Обоснование на месте.** Никаких «как мы знаем» и отсылок к другим файлам серии: каждый документ вводит свои термины сам и показывает каждое утверждение на числах прямо там, где оно сказано.
- **Честная оговорка.** Где модель заметно расходится с реальностью — абзац о том, в чём она врёт и что всё равно остаётся верным (образец: про рост человека в `01`).
- **Тон.** Русский, на «ты», ровно и уважительно. Без морализаторства, без меты («в этой главе мы», упоминаний курса/файлов/занятий), без сюсюканья. Вывод должен быть заработан картинкой, а не объявлен.
- **Сцена осмысленна без единого касания.** Ползунки и кнопки — усиление, а не условие понимания.

## Правки и сдача

- Имя нового файла — латиницей, с номером занятия впереди (`04-shum.html`, …). Номера 01–03 заняты циклом про два вида распределений. Новый документ добавляется и в таблицу `README.md`, и в `index.html`.
- Перед сдачей: открыть документ, просмотреть каждую сцену — ничего не наезжает, текст на канве не обрезан, на узком экране читается, «ещё раз» перезапускает, автоперезапуск не рвёт чтение раньше времени.
- Сообщения коммитов — на русском, в повелительном/инфинитивном наклонении («Вернуть главный тезис…», «Номер занятия в имени файла…»).
